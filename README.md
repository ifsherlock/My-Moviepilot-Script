# MoviePilot 种子名自动测试与下载 (增强版) 使用api登录
**🛠️ 核心改进：**
将原有的网页登录逻辑改成了 **API 形式访问**，完美解决了 MoviePilot (MP) 开启两步验证（2FA）后，传统脚本无法登录和使用的问题。


本项目基于以下两个开源脚本的源代码进行修改与二次开发，在此向原作者表示感谢：
* [MoviePilot 种子名自动测试与下载 (增强版)](https://greasyfork.org/zh-CN/scripts/569257-moviepilot-%E7%A7%8D%E5%AD%90%E5%90%8D%E8%87%AA%E5%8A%A8%E6%B5%8B%E8%AF%95%E4%B8%8E%E4%B8%8B%E8%BD%BD-%E5%A2%9E%E5%BC%BA%E7%89%88)
* [MoviePilotNameTest](https://greasyfork.org/zh-CN/scripts/473246-moviepilotnametest)

## NotePod++ FNOS 助手

安装链接：[NotePod++ FNOS 助手.user.js](https://raw.githubusercontent.com/ifsherlock/My-Moviepilot-Script/main/NotePod%2B%2B%20FNOS%20%E5%8A%A9%E6%89%8B.user.js)

用于在 FNOS 文件管理器中添加 NotePod++ 编辑和新建文件辅助功能。脚本默认只匹配 `fnos.net`、`:5666`、`:5667`，其它域名、IP 或端口请在脚本菜单 `NotePod++：设置` 中本地配置。
